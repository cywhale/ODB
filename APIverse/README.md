# Ocean APIverse

https://api.odb.ntu.edu.tw/hub

This site is developed and maintained by Ocean Data Bank (ODB), National Science and Technology Council, Taiwan. It provides tryout, demonstration, and sharing for ocean open data services (mainly geographic layers and Open API).

The main features include Open API specifications (OAS) interfaces, API data flow design, 3D globe viewer, and customizable geographic layers. Some features require logging in. The documentation on this site is available in both Mandarin and English.

ODB Open API ODB CTD/SADCP API, ECO API, Global Marine Heatwaves, GEBCO topography, Tide (TPXO9-atlas-v5), WOA23 (World Ocean Atlas 2023), GLODAP API, and OGC WMS/WMTS capabilities API.


本站為國家科學及技術委員會海洋學門資料庫（Ocean Data Bank, ODB）開發維護之海洋資訊交流平台，提供海洋開放資訊服務（主要為地理圖資與 Open API）之試用、展示與分享。
主要功能包含 Open API 規格（OAS）界面、API 資料流設計、3D 地球圖台與自訂地理圖層等，部份功能須登入使用。本站說明均有中英文對照。

## Features

#### Gallery

  You can open the gallery of Ocean APIverse examples via footer toolbox and browse them. For example:
  
  [SADCP API showcase](https://api.odb.ntu.edu.tw/hub/?gallery=sadcp)
    
#### API Pipeline
   
  Use [Data flow](https://api.odb.ntu.edu.tw/hub/pipe) features that demonstrate the API pipeline concepts. Examples of data-flow JSON: ./dataflow

#### 3D Earth

  Use [Globe Viewer](https://api.odb.ntu.edu.tw/hub/earth) features to visualise ODB Open APIs' data and overlay multiple WMS/WMTS layers.
